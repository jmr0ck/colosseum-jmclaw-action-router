# BlinkGuard Operator Website

Hackathon landing site for the Frontier positioning of BlinkGuard Operator.

## Run locally

```bash
cd website
npm install
npm run dev
```

Open:

- http://localhost:3000
- or the port shown by Next.js if 3000 is busy

## Routes

- `/` — main landing page
- `/demo` — demo walkthrough page
- `/architecture` — system design / trust engine page

## Notes

This site is intentionally separate from the existing BlinkGuard MVP in the repo root.
It is the marketing / hackathon presentation layer for the Frontier submission direction.
